# Diff viewer plugin
- Independent workspace: `@manuelselch/pi-plugin-diff-viewer`; no Chat or Server imports.
- Conditional root exports load host or web declarations. Explicit `/host` and `/web` exports are also available.
- Browser consumers supply React/Mantine/Tabler peers, scan web entry classes with Tailwind v4 and provide the `--pi-*` theme tokens used by Chat.
- Web entry contributes the **Changes** tab at the generic `side-panel` placement only while a transcript is open. Its provider owns per-project comparison preferences and session-scoped review drafts; closing the panel stops diff reads/render workers while in-flight batch delivery can finish.
- Host entry provides read-only context, recent-commits and diff RPC methods through contract version 2 (required context suggestions; commits input is projectPath only). Chat explicitly registers both environments and allowlists the contract.
- **Uncommitted** compares HEAD (or an unborn repository’s empty tree) with the working tree. **Branch** is the default mode and compares the selected base’s merge-base with HEAD against the working tree. **Commit** defaults to the latest commit and compares the selected commit with its first parent (or the empty tree for a root commit).
- Stable comparison buttons keep the selected name visible; branch search opens separately via **Search all branches…**, with an icon-only back action. Mode selection is a non-searchable menu. No duplicate current-branch label or hover tooltips.
- Initial branch choices: selected base, repository default and up to two **Suggested** local ancestors, ranked by commits from their tips to HEAD. Default uses locally known remote HEAD (preferring origin), then main/master; local refs are preferred. Same-tip default/current candidates are not suggestions. This is a heuristic, not parent detection; advanced/non-ancestor stack bases remain searchable, with no PR lookup or network fetching.
- Full search includes all local and locally available remote-tracking refs, including the current branch; current-tip refs are excluded from suggestions only. A remote counterpart at the same tip as its matching local branch is represented once; different tips retain their remote-prefixed names without technical tip labels.
- Commit mode offers only five recent commits from HEAD ancestry, newest first with **Latest** on the first; no commit search or pagination. Labels never display hashes. Per-project selections survive mode changes and panel close/reopen, including a chosen commit aging out of the recent list.
- Changed files use collapsible **Source / Tests / Docs / Config** groups without dividers or a Files header. Each group retains a folders-first, alphabetical tree with compact single-child folder paths and changed-file counts. Navigation can be resized horizontally; full-path filtering (case-insensitive) narrows navigation, the continuous diff stream and footer totals. Collapsing a kind/folder affects navigation only. Tree and diff order match; file buttons retain full-path accessible labels without tooltips.
- Kind classification is a path heuristic: test directories (`test`, `tests`, `testing`, `__tests__`, `e2e`, `spec`) and `.test`/`.spec` filenames take precedence, then docs directories/Markdown and conventional documentation names, then config directories, config filenames, dotfiles and common configuration/lock extensions; remaining files belong to Source (including styles and assets). No Git/API changes or feature inference.
- Unified diffs wrap long lines by default; **Wrap lines** toggles per-file horizontal scrolling with fixed gutters and full-width diff backgrounds. Deleted files start collapsed; their headings expand/collapse the removed lines. File navigation retains accessible full paths without hover tooltips.
- Rendering uses a lazy-loaded `@pierre/diffs` virtualized multi-file view and two highlighting workers. Host theme tokens style its shadow root; no global theme changes. Generated files stay plain without truncation. [Rendering and review details](docs/review.md).
- Inline single-line comments support compact save/cancel controls and keyboard shortcuts. Session/project/comparison-scoped drafts survive panel toggles; send them as one contextual agent message without modifying the composer. Stale anchors block submission; uncertain delivery retains comments without retrying automatically.
- Includes staged, unstaged and non-ignored untracked files. Renames appear as deletion/addition. Binary and metadata-only changes have explicit placeholders; symlinks display link text.
- Git uses argument arrays, disabled external diff/textconv, timeouts and bounded output. Comparisons over 200 files or 2 MiB fail clearly rather than silently truncating. No staging, reverting, editing, polling or remote network operations.
- Colocated domain, Git-fixture and DOM tests cover parsing, comparison modes, names, cancellation and file navigation. Root plugin discovery includes build, typechecks, tests, lint, coverage and artifact checks.
